# Japan October 2026

Лендинг авторского путешествия по Японии с 12 по 20 октября 2026 года: Токио, Осака, Киото и Нара.

**Сайт:** https://wertikooo-web.github.io/japan-october-2026/

## О путешествии

- 9 дней в Японии и 8 ночей
- 4 ночи в Токио и 4 ночи в Осаке
- группа до 8 человек
- Токио, Осака, Киото и Нара в одном маршруте
- организатор — Alexei Ivantov

## Возможности сайта

- девять интерактивных глав маршрута: от Дня 1 до Дня 9;
- тематическое видео для каждого дня;
- единая кнопка включения и выключения звука для всех видео;
- полноценное переключение интерфейса и глав между русским, румынским и английским языками;
- адаптивная версия для компьютеров и мобильных устройств;
- быстрый переход к WhatsApp и электронной почте организатора.

## Структура

- `index.html` — разметка, стили, тексты, переводы и логика страницы;
- `assets/` — изображения, постеры и оптимизированные видео;
- `README.md` — описание проекта.

## Локальный запуск

Сайт статический и не требует сборки:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Переводы маршрута

Русский оригинал дней хранится в массиве `days`, английская и румынская версии — в `dayTranslations`. Для каждого дня переводятся дата, заголовок, маршрут, основной текст и список впечатлений.

## Видео и звук

Видео запускаются автоматически без звука в соответствии с ограничениями современных браузеров. После нажатия общей кнопки «ЗВУК» активное видео получает звук, а выбранное состояние сохраняется при переключении глав и языков.

Для совместимости рекомендуется использовать MP4 с видео H.264, аудио AAC, пиксельным форматом `yuv420p` и флагом `faststart`.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`. После обновления ветки публикация обычно занимает несколько минут.
